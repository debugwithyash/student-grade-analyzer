# 🎓 Student Grade Analyzer

A responsive **Student Grade Analyzer** built using **HTML, CSS, and JavaScript**. This project calculates a student's total marks, percentage, grade, pass/fail status, performance, and scholarship eligibility with a clean and user-friendly interface.

## 🌐 Live Demo

🔗 https://debugwithyash.github.io/student-grade-analyzer/
